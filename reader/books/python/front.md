## Python: da primeira ideia ao projeto real
Este é um livro para quem nunca programou. Começamos com perguntas, desenhos de fluxo e casos de teste; só depois usamos a sintaxe de Python. As lições avançam até bibliotecas de dados, APIs, bots e aprendizado de máquina. Leia uma página por vez, execute os exemplos e tente explicar a regra com suas palavras. Não é preciso decorar tudo: saber experimentar, consultar documentação e verificar resultados é parte do aprendizado.
## Como usar o laboratório
Cada lição tem um exercício abaixo das páginas. Digite código Python no editor, pressione “Executar” para ver saída e “Corrigir” para rodar testes. Antes de clicar, preveja o resultado. Se falhar, leia qual caso não passou; altere uma coisa e tente de novo. A solução aparece quando você pedir, com explicação. O corretor verifica casos selecionados, não prova que todo programa possível está correto.
## Python no navegador e no computador
O laboratório usa Pyodide, Python compilado para WebAssembly, dentro de um Web Worker. O código do exercício é executado no seu navegador, sem ser enviado ao servidor do Voidwielder. Na primeira vez, o runtime precisa ser carregado de uma CDN, então é necessário acesso à internet. Bibliotecas que dependem de sistema, navegador automatizado ou serviço externo devem ser estudadas num projeto local; o livro indica quando isso ocorre.
## Ambiente recomendado
Para projetos completos, instale Python de uma fonte oficial, use um editor, Git e um ambiente virtual por projeto. UV pode ajudar a gerenciar dependências e executar comandos. O laboratório do livro cobre a lógica sem exigir instalação imediata. Quando um comando menciona terminal, adapte `python` ou `python3` conforme seu sistema. Não altere o Python usado pelo sistema operacional apenas para acompanhar um exemplo.
## O caminho em treze partes
As primeiras partes tratam de algoritmos, valores, decisões, laços e coleções. Depois vêm funções, módulos, arquivos, testes e orientação a objetos. Recursos avançados e biblioteca padrão preparam a entrada em NumPy, pandas e gráficos. APIs, automação e bots mostram aplicações reais; machine learning aparece junto da avaliação de dados. Banco de dados, produção e projeto final encerram o percurso. Volte ao sumário sempre que uma etapa precisar de revisão.
## Convenções de código
Trechos em bloco são exemplos para ler e, quando indicado, executar. Nomes em crases, como `print`, são comandos, tipos ou funções. O livro usa Python moderno e exemplos pequenos, sem depender de dados privados. Uma saída como `True` deve ser entendida pelo caso que a gerou, não apenas copiada. Valores de exemplo podem ser trocados para investigar fronteiras. Consulte a versão da documentação da biblioteca instalada no seu projeto.
## Cuidados com código e dados
Não cole senhas, chaves de API, dados de clientes nem arquivos pessoais no editor de exercícios. Bots e APIs podem alterar sistemas externos; pratique primeiro em dados fictícios e serviços locais que você controla. Um programa que passa nos testes ainda precisa de revisão de segurança, privacidade e regras do domínio antes de servir pessoas reais. Em machine learning, considere de onde vieram os dados e quem será afetado por uma previsão errada.
## Seu compromisso de aprendizagem
Escolha um problema simples que gostaria de resolver com Python: organizar tarefas, analisar notas ou automatizar um relatório. Escreva o objetivo, três entradas e uma saída antes da primeira lição. Mantenha um caderno com hipótese, código, erro, correção e conclusão. No projeto final, compare sua primeira descrição com o programa que consegue construir. O avanço aparece quando você consegue explicar e testar uma solução sem depender de copiar um exemplo inteiro.
