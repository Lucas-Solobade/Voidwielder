# Instalar e abrir Python
## Duas formas de começar
O laboratório interativo deste livro roda Python dentro do navegador; você pode experimentar sem instalar nada. Para projetos próprios, instale uma versão suportada a partir de python.org ou do gerenciador da sua distribuição. Verifique a versão com `python --version` ou `python3 --version`, conforme sistema. Não há necessidade de trocar o Python usado pelo sistema operacional para concluir os exercícios.
## O interpretador interativo
No terminal, `python` abre um prompt `>>>` onde cada expressão pode ser avaliada. Digite `2 + 3` e observe `5`; depois `print("Olá")`. Para sair, use `exit()` ou atalho indicado pelo terminal. O prompt serve para explorar uma ideia pequena; um arquivo `.py` serve para repetir e compartilhar um programa. O editor do livro executa código completo a cada tentativa.
## Seu primeiro arquivo
Crie `ola.py` com `print("Olá, mundo!")` e rode `python ola.py`. O caminho da ferramenta e o diretório atual importam; se aparecer “arquivo não encontrado”, confira `pwd` ou o endereço da pasta. Use um editor de texto simples ou um ambiente de desenvolvimento. A extensão identifica o tipo de arquivo, mas é o interpretador que lê e executa as instruções.
## Comentários e nomes
```python
# Uma mensagem para quem está aprendendo
nome = "Lia"
print("Olá,", nome)
```
O caractere `#` inicia um comentário até o fim da linha. `nome` é uma variável; `print` é uma função pronta. Comentários explicam intenção, não precisam repetir exatamente o que o código já mostra. Escolha nomes descritivos: `nome_aluno` comunica mais que `n`. Salve o arquivo em UTF-8 para escrever acentos com segurança.
## Erro de sintaxe sem medo
Se faltar uma aspa ou parêntese, Python mostra `SyntaxError` com posição aproximada. Leia a linha indicada e também a anterior: um delimitador aberto pode causar erro depois. Erro é informação, não fracasso. Copie a mensagem no caderno e tente prever a correção antes de editar. Evite alterar várias linhas de uma vez, pois isso torna difícil descobrir o que resolveu.
## Ambiente local e navegador
O laboratório deste site usa Pyodide, que executa Python no navegador em um Web Worker. Ele é ótimo para conceitos e exercícios pequenos, mas não substitui um computador para serviços, automação de desktop ou acesso a todos os pacotes. Em páginas avançadas, os exemplos de bibliotecas mostram instalação local. O código digitado no laboratório fica neste navegador; não use dados sigilosos nele.

# Expressões, valores e operadores
## Python calcula expressões
Uma expressão produz um valor: `4 * 3` produz 12; `7 > 5` produz `True`. Python respeita precedência, mas parênteses deixam intenção explícita. `2 + 3 * 4` resulta 14, enquanto `(2 + 3) * 4` resulta 20. Antes de pedir ao computador a resposta, calcule no papel. Quando há dinheiro ou medidas, anote também unidade e regra de arredondamento.
## Inteiros e decimais
`int` representa inteiros de tamanho variável; `float` representa números de ponto flutuante com precisão finita. `10 / 2` produz `5.0`, pois `/` devolve divisão comum. `10 // 3` produz quociente inteiro 3, e `10 % 3` produz resto 1. Resto é útil para testar paridade: `numero % 2 == 0`. Não use `float` como representação exata de centavos em sistema financeiro.
## Texto também é valor
`"Python"` é uma string. `"Py" + "thon"` concatena textos; `"ha" * 3` repete. `"5" + "2"` produz `"52"`, não 7. A aparência de algarismo não transforma string em número. `int("5")` converte quando o texto é válido; `int("cinco")` gera erro. Valide entradas antes de usá-las em cálculos e não esconda falhas de conversão.
## Compare corretamente
```python
print(8 == 8)   # True
print(8 != 3)   # True
print(4 <= 7)   # True
```
`==` compara; `=` atribui um valor a um nome. Confundir esses símbolos causa erro de sintaxe ou lógica. Comparações podem ser combinadas com `and`, `or` e `not`. Escreva uma tabela de verdade para duas condições simples antes de montar uma regra longa, como “idade suficiente e inscrição confirmada”.
## Potência e ordem
`**` calcula potência: `2 ** 3` é 8. O operador `-` serve para subtração e sinal negativo. Use parênteses para tornar uma fórmula de média, juros ou área verificável por outra pessoa. Um programa não garante que a fórmula escolhida é a correta; confira a regra do domínio. Num exercício escolar, um resultado plausível pode estar errado por ordem de operações.
## Experimente fronteiras
Teste divisão por zero e observe `ZeroDivisionError`. Teste `0.1 + 0.2` e perceba a representação aproximada do ponto flutuante. Pergunte qual tolerância a tarefa admite. Para contagem e índices, inteiros são naturais; para valores monetários, `decimal.Decimal` pode ser apropriado, com entrada textual. Escolha tipo conforme significado, não apenas conforme o que Python aceita.

# Variáveis, tipos e conversões
## Um nome aponta para um valor
`idade = 18` faz `idade` referir-se ao inteiro 18. Depois, `idade = 19` muda a associação. Python é dinamicamente tipado: o valor tem tipo, e o nome pode apontar para valores de tipos diferentes. Isso oferece flexibilidade, mas mudanças inesperadas confundem. Use nomes consistentes e não reatribua `idade` com uma mensagem textual quando a função precisa de um número.
## Tipos essenciais
Os primeiros tipos são `int`, `float`, `str`, `bool` e `None`. `type(valor)` ajuda a investigar. `None` significa ausência de valor, não zero nem string vazia. `bool(0)` é falso e `bool(3)` é verdadeiro, mas regras de negócio devem usar condições explícitas. Uma entrada vazia pode significar “não informado” ou “zero”; a decisão deve vir do problema, não de coerção automática.
## Entrada do usuário é texto
```python
texto = "12"  # Simula input() no laboratório
quantidade = int(texto)
print(quantidade * 2)
```
`input()` recebe texto no terminal. No laboratório, os exercícios evitam entrada interativa e usam funções com argumentos, para que a correção seja automática. Em programa real, trate texto vazio, espaços e valores inválidos antes de converter. Não faça `int(input())` numa aplicação grande sem pensar na mensagem de erro para o usuário.
## f-strings claras
`nome = "Lia"` e `f"Olá, {nome}!"` criam uma string formatada. Dentro de chaves, uma expressão é avaliada. `f"Total: {preco:.2f}"` exibe duas casas decimais, mas a formatação não corrige erro numérico anterior. Use f-strings para mensagens; para códigos e identificadores, evite formatação que remova zeros à esquerda sem intenção. Textos destinados ao público merecem revisão como qualquer interface.
## Conversão e validação
`int(" 42 ")` aceita espaços ao redor; `int("4,2")` não interpreta vírgula decimal. `float("4.2")` usa ponto no formato padrão. Validar significa decidir o conjunto permitido e comunicar quando a entrada está fora dele. Se a pessoa digita idade negativa, converter com sucesso não torna o dado válido. Separe “consigo interpretar” de “faz sentido para a tarefa”.
## Nomeie constantes
Python não impede reatribuir nomes em maiúsculas, mas a convenção `LIMITE = 10` sinaliza que o valor deve permanecer fixo. Uma taxa ou limite mágico espalhado por cinco linhas dificulta manutenção. Centralize e explique a origem. Use `snake_case` para variáveis e funções. Evite nomes como `list`, `str` e `sum`, que escondem funções e tipos embutidos importantes.
