# Condições que expressam regras
## Perguntas que o programa responde
Uma condição é uma pergunta cuja resposta é verdadeira ou falsa. “A nota é pelo menos 7?” vira `nota >= 7`. Para escrever boa condição, liste fronteiras: 6,9; 7; 7,1. Um `if` escolhe um bloco conforme a resposta. Indentação não é decoração em Python: ela define quais linhas pertencem a cada caminho. Use quatro espaços por nível e evite misturar espaços e tabulações.
## if, elif e else
```python
def situacao(nota):
    if nota < 0 or nota > 10:
        return "nota inválida"
    elif nota >= 7:
        return "aprovado"
    else:
        return "revisar"
```
A validação vem antes da classificação. `elif` só é testado se os ramos anteriores falharam. `return` termina a função e entrega um resultado. Assim, a função é fácil de chamar em vários testes sem depender de `print` ou entrada do teclado.
## Combinar regras
`and` exige duas condições verdadeiras; `or` exige ao menos uma. `not` inverte. Python avalia da esquerda para a direita e pode parar cedo, chamado curto-circuito. Em `idade >= 18 and autorizado`, o segundo termo importa apenas se o primeiro for verdadeiro. Use parênteses quando a precedência não estiver óbvia. Uma regra jurídica ou empresarial precisa ser validada com quem conhece o domínio.
## Pertinência e identidade
`"a" in "casa"` testa presença; `item in lista` procura membro. `is` compara identidade de objetos, não igualdade de valores; para valores, use `==`. A exceção comum é `valor is None`, pois `None` é um objeto único. Evite `if valor == True` quando `if valor` expressa a intenção, mas não confunda verdade genérica com uma regra específica como “quantidade maior que zero”.
## Erro de fronteira
`idade > 18` exclui quem tem exatamente 18 anos; `idade >= 18` inclui. Esse erro aparece muito em limites de desconto, prazo e faixa etária. Escreva três testes para cada limiar: imediatamente antes, exatamente nele e imediatamente depois. Quando valores são decimais, escolha números coerentes com a unidade e precisão. Os testes devem ser legíveis por alguém que não escreveu o código.
## Separe decisão de apresentação
Uma função que devolve `"aprovado"` pode ser usada em site, terminal e relatório. `print` dentro da função fixa a apresentação e dificulta testes. Primeiro calcule a resposta; depois o programa principal decide como mostrar. Essa separação é a base de aplicações maiores. No laboratório, a correção chama sua função com várias entradas, inclusive uma que você talvez não tenha pensado.

# Repetição com while
## Quando repetir
Um laço executa um bloco várias vezes. `while` continua enquanto uma condição for verdadeira. É útil quando não sabemos antecipadamente quantas tentativas serão necessárias, como ler registros até encontrar um marcador. Todo laço precisa de progresso rumo à parada. Antes de escrever, responda: qual estado muda a cada volta e em que situação a condição se torna falsa?
## Contador simples
```python
contador = 1
while contador <= 3:
    print(contador)
    contador += 1
```
O programa imprime 1, 2 e 3. Se esquecer `contador += 1`, a condição permanece verdadeira e o programa não termina. No laboratório do livro, uma execução longa é interrompida para proteger a página. No terminal, Ctrl+C costuma interromper, mas é melhor compreender e corrigir a condição.
## Invariante do laço
Uma invariante é uma afirmação que permanece verdadeira em cada passagem e ajuda a provar o algoritmo. Ao somar números de 1 até `n`, depois de processar `k` valores, `soma` contém exatamente a soma deles. Podemos verificar isso à mão para 1, 2 e 3. Essa ideia parece formal, mas é prática: se um valor se perde, identifique a primeira volta em que a afirmação deixa de valer.
## Sentinela e tentativas
Uma sentinela é um valor que indica término, como `"fim"` numa sequência de entradas. Não use uma palavra que possa ser dado válido sem definir escape. Limitar tentativas evita laços intermináveis quando um serviço não responde. Em bots e automações, `while True` sem pausa e limite pode consumir recursos e repetir ações indevidas. Faça primeiro uma simulação com poucos itens.
## break e continue
`break` encerra o laço imediatamente; `continue` pula para a próxima volta. Ambos têm uso, mas podem esconder fluxo quando aparecem muitas vezes. Procure uma condição de parada clara. Para encontrar o primeiro item adequado, `break` faz sentido; para ignorar um item inválido, `continue` pode ajudar. Desenhe onde o controle vai depois de cada comando para evitar pular atualização do contador.
## Somando com estado
Para acumular, comece `total = 0` e, em cada volta, use `total += valor`. Depois de quatro valores, total é a soma dos quatro. Se inicializar com o primeiro item e ainda somá-lo no laço, contará duas vezes. Teste lista vazia, um item e vários. O valor inicial é parte do algoritmo, não detalhe de sintaxe.

# for, range e percurso
## Repetição sobre coleção
`for item in itens:` percorre cada elemento de uma coleção. Diferente de um contador manual, não precisamos atualizar índice para avançar. `range(5)` produz 0, 1, 2, 3 e 4; o limite final não entra. Essa convenção combina com índices de listas e é fonte comum de erro inicial. Faça uma tabela para `range(2, 7, 2)` e confira a sequência resultante.
## Conte sem indexar
```python
nomes = ["Ana", "Bia", "Caio"]
for nome in nomes:
    print(nome)
```
Esse laço lê diretamente os valores. Não use `range(len(nomes))` quando não precisa do índice. Se precisar de posição e valor, `enumerate(nomes, start=1)` entrega ambos de forma clara. Uma lista vazia executa zero voltas, então pense em qual resultado deve permanecer após o laço.
## Acumulador e filtro
Para somar valores positivos, inicie `total = 0`, percorra números e some apenas `numero > 0`. A ordem importa: o filtro deve ser testado antes da soma. Separe “selecionar” de “acumular” ao explicar. Em dados empresariais, uma regra de filtro mal definida altera métricas sem causar exceção; por isso inclua testes com negativo, zero, positivo e coleção vazia.
## range e passo
`range(inicio, fim, passo)` gera inteiros até antes do fim, respeitando sinal do passo. `range(5, 0, -1)` conta 5, 4, 3, 2, 1. `range(0, 5, 0)` gera erro porque passo zero não avança. Não use `range` como substituto de qualquer laço: para objetos de uma coleção, percorrer valores costuma ser mais expressivo.
## Laços aninhados
Um laço dentro de outro pode percorrer linhas e colunas de uma grade. Se há 4 linhas e 3 colunas, o corpo interno roda 12 vezes. Esse produto cresce rápido; com um milhão de itens em cada laço, teríamos operações demais para um exercício simples. Antes de otimizar, conte quantas voltas o algoritmo faz e procure uma estrutura de dados melhor se necessário.
## else em laços
Python permite `else` após `for` ou `while`: esse bloco roda quando o laço termina sem `break`. Pode expressar “não encontrei”, mas surpreende iniciantes. Use apenas quando melhora leitura e teste os dois casos. Para primeira versão, uma variável `encontrado` pode ser mais clara. Código profissional valoriza entendimento da equipe, não uso máximo de recursos da linguagem.
