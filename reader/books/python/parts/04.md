# Strings: texto como dado
## Sequência de caracteres
Uma `str` representa texto Unicode. Podemos ler caracteres com índices: `"casa"[0]` é `"c"`; índices negativos contam do fim. Uma fatia `texto[1:3]` inclui posições 1 e 2, não 3. A string é imutável: não se troca uma letra diretamente por atribuição de índice. Para transformar texto, produza uma nova string e associe-a a um nome.
## Limpeza cuidadosa
```python
nome = "  Ana Silva  "
limpo = nome.strip()
print(limpo.casefold())
```
`strip` remove espaços das pontas; `casefold` ajuda comparações sem distinguir caixa em muitos idiomas. Não remova todos os espaços: nomes compostos precisam dos internos. Normalização pode afetar identidade e apresentação; guarde também o original quando os dados tiverem importância. Busca tolerante e armazenamento de nome oficial são tarefas diferentes.
## Procurar e substituir
`"python" in frase` verifica presença; `frase.find("python")` devolve índice ou −1. `replace` cria novo texto com substituições. Para separar palavras simples, `split()` ajuda, mas arquivos CSV exigem parser próprio porque aspas e vírgulas têm regras. Uma solução de texto deve ser testada com acentos, pontuação, vazio e espaços repetidos conforme o domínio.
## Formatar para pessoas
F-strings combinam valores e texto: `f"Olá, {nome}!"`. Formatos como `{valor:.2f}` controlam exibição. Construa mensagens que explicam unidades, não apenas números soltos. Se o texto será mostrado em HTML, use o mecanismo de escape do framework para não transformar entrada de usuário em código da página. Python cria a string; a camada de saída decide como exibi-la com segurança.
## Codificação e bytes
Unicode define caracteres; UTF-8 transforma texto em bytes para arquivo ou rede. `"ação".encode("utf-8")` devolve `bytes`; `dados.decode("utf-8")` recupera texto quando o conteúdo é válido. Erros de acento geralmente envolvem codificações diferentes, não uma falha do `print`. Ao abrir arquivo, indique `encoding="utf-8"` quando apropriado e saiba qual codificação a fonte realmente usa.
## Expressões regulares com moderação
O módulo `re` encontra padrões, mas nem toda busca precisa dele. Para saber se uma palavra aparece, `in` pode ser suficiente. Uma regex mal escolhida pode aceitar informação inválida ou ficar difícil de manter. Se usar `re.fullmatch`, teste entradas completas, não apenas trechos. Em páginas futuras, veremos bibliotecas para dados estruturados que evitam analisar manualmente HTML ou CSV com regex.
## Verifique e pratique
Preveja `"Python"[1:4]`, `" oi ".strip()` e `"Casa".casefold()`. Escreva uma função que recebe um nome com espaços nas pontas e devolve saudação com nome limpo. Teste vazio e nome composto. Na atividade, extraia as iniciais de duas palavras sem modificar o texto original.

# Listas, tuplas e índices
## Uma sequência mutável
Lista guarda valores em ordem e permite alterações: `tarefas = ["ler", "praticar"]`. `append` acrescenta ao fim; `pop` remove e devolve um item. Índices começam em zero. Antes de acessar `tarefas[2]`, verifique se há terceiro elemento. Uma lista pode misturar tipos, mas uma coleção com propósito claro costuma ser mais fácil de entender se os itens têm formato consistente.
## Fatias e cópias
```python
notas = [6, 8, 10]
primeiras = notas[:2]
notas.append(7)
print(primeiras, notas)
```
A fatia criou uma nova lista externa, então `primeiras` continua `[6, 8]`. Entretanto, numa lista de listas, uma cópia rasa ainda compartilha elementos internos. Distinga identidade de igualdade: `a == b` compara conteúdo; `a is b` verifica se são o mesmo objeto. Esse detalhe importa quando uma função altera uma coleção recebida.
## Percorrer com clareza
`for nota in notas:` lê valores. Se precisar atualizar posição, `for indice, nota in enumerate(notas):` dá índice e valor. Remover elementos de uma lista enquanto a percorre pode pular itens; prefira construir nova lista com os que ficam. Essa escolha também preserva entrada original para comparação. Em dados grandes, desempenho pode importar, mas primeiro garanta a regra correta.
## Tupla e intenção
Tupla é sequência imutável: `coordenada = (3, 5)`. Use-a para um registro curto cujas posições tenham significado estável ou para retornar vários valores: `x, y = coordenada`. Imutabilidade da tupla não torna objetos internos imutáveis: uma lista dentro dela ainda pode mudar. Para registros com muitos campos, nomes explícitos ou `dataclass` serão mais legíveis que decorar posição 7.
## Ordenar e agregar
`sorted(notas)` produz nova lista ordenada; `notas.sort()` modifica a lista existente. `min`, `max` e `sum` ajudam com números, mas `min([])` falha sem valor padrão. `len` conta itens. Não use nome `sum` para variável se quer chamar a função depois. Sempre pergunte se a ordem original é importante antes de ordenar dados de negócio.
## Complexidade inicial
Percorrer uma lista com `for` custa trabalho proporcional ao número de itens, chamado O(n). Procurar um valor sem índice também costuma visitar vários elementos. Inserir no começo desloca os demais. Não precisa decorar tabelas de complexidade agora; observe o que acontece se a coleção cresce de 10 para 10 mil itens. Escolher estrutura adequada pode importar mais que micro-otimizações.
## Verifique e pratique
Crie lista de quatro temperaturas. Calcule média com `sum` e `len`, tratando a lista vazia. Compare `sorted(lista)` e `lista.sort()` num teste. Na atividade, escreva uma função que devolve o maior valor sem modificar a entrada; inclua caso de lista vazia no contrato.

# Dicionários e conjuntos
## Chave leva a valor
Dicionário associa chaves a valores: `aluno = {"nome": "Ana", "nota": 8}`. `aluno["nome"]` lê um campo; uma chave ausente gera `KeyError`. `aluno.get("turma")` devolve `None` se não existir, ou um padrão escolhido. Use chaves com significado e valide os campos obrigatórios. Dados JSON de APIs frequentemente viram dicionários, mas não assuma que toda resposta tem o formato esperado.
## Contagem por chave
```python
contagens = {}
for fruta in ["maçã", "pera", "maçã"]:
    contagens[fruta] = contagens.get(fruta, 0) + 1
print(contagens)
```
O resultado conta ocorrências. O módulo `collections.Counter` faz isso de forma pronta e será estudado depois. Primeiro entenda o algoritmo: para cada item, ler contagem anterior, somar um e guardar. Faça o rastreamento manual para uma lista vazia e outra com itens repetidos.
## Percorrer pares
`for chave, valor in dados.items():` percorre pares. Se só precisa de chaves, percorra o dicionário ou use `.keys()`; para valores, `.values()`. A ordem de inserção é preservada em Python moderno, mas uma regra de negócio não deve depender de ordem acidental se puder usar `sorted`. Uma chave precisa ser hashable; uma lista mutável não serve como chave comum.
## Conjunto elimina repetição
`set([1, 1, 2])` resulta num conjunto com 1 e 2. Conjuntos apoiam união, interseção e testes de pertencimento. A ordem de apresentação não é o objetivo dessa estrutura. Para encontrar alunos presentes em duas turmas, interseção pode ser expressiva. Se você precisa manter ordem original sem repetição, combine uma estratégia diferente em vez de confiar no conjunto para exibir sequência.
## Escolher estrutura
Use lista para sequência ordenada e mutável; tupla para registro curto e estável; dicionário para acesso por chave; conjunto para unicidade e operações de membros. Nenhuma é superior em toda situação. Pergunte como os dados serão lidos, alterados e exibidos. Em um sistema de empresa, escolher identificador único confiável para chave é mais importante que a sintaxe da estrutura.
## Cópia e aninhamento
Um dicionário pode conter listas e outros dicionários. `dados.copy()` copia apenas a camada externa; estruturas internas continuam compartilhadas. Para dados JSON independentes, `copy.deepcopy` pode ajudar, mas tem custo e nem todo objeto é copiável. Antes de copiar tudo, determine se uma função pode trabalhar sem mutar entrada. Imutabilidade por convenção reduz surpresas e facilita testes.
## Verifique e pratique
Monte um dicionário de produto com nome, preço e estoque. Liste chaves obrigatórias, trate ausência de preço e conte quantos produtos têm estoque positivo. Na atividade, complete uma função que conta palavras de uma lista usando dicionário. Teste vazio, repetidos e palavras que diferem em maiúsculas, decidindo a regra de normalização.
