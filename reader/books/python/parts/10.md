# NumPy e pensamento vetorial
## Por que outra estrutura
Listas Python são flexíveis, mas operações numéricas em muitos valores podem ficar lentas e verbosas. NumPy oferece `ndarray`, uma matriz homogênea com operações otimizadas. Instale no ambiente do projeto com `uv add numpy` ou `python -m pip install numpy`. Em seguida use `import numpy as np`. Não instale pacote globalmente por hábito; documente a dependência e teste em ambiente limpo.
## Primeiro array
```python
import numpy as np

valores = np.array([2, 4, 6])
print(valores * 3)
print(valores.mean())
```
Multiplicar o array por 3 aplica operação a cada elemento, diferente de lista Python, cuja multiplicação repete a sequência. Essa diferença semântica merece teste. `mean` devolve média numérica; confirme tipo e tratamento de vazio. NumPy é excelente para dados homogêneos, não substitui dicionários ou classes do domínio.
## Forma e dimensão
`shape` descreve dimensões: matriz de 2 linhas e 3 colunas tem `(2, 3)`. `ndim` informa quantidade de eixos e `dtype` o tipo dos elementos. Antes de combinar arrays, escreva formas no papel. Um erro de shape pode denunciar dados montados incorretamente. Não faça `reshape` apenas para silenciar erro; confirme se a nova organização preserva o significado de cada linha e coluna.
## Indexar e fatiar
`matriz[0, 1]` lê linha 0, coluna 1. Fatias podem criar views que compartilham memória com o array original. Modificar uma view pode alterar os dados de origem; use `.copy()` quando quer independência. Isso difere de algumas expectativas com listas. Teste com array pequeno e observe antes e depois. Em análise de dados, alteração silenciosa de base pode contaminar resultados.
## Broadcasting explicado
NumPy combina arrays de formas compatíveis sem copiar explicitamente valores em muitos casos. Somar um escalar a vetor é simples; somar vetor de três colunas a matriz de duas linhas também pode funcionar. A operação alinha dimensões a partir do fim. Se não combinam, surge erro. Antes de usar, desenhe formas e o significado de cada eixo, evitando resultado numericamente válido mas semanticamente errado.
## Ausência e precisão
`np.nan` representa um valor numérico ausente em muitos fluxos, mas propaga-se em operações comuns. `np.nanmean` pode ignorá-lo conforme contrato. Distinga ausência, zero e valor inválido. Tipos inteiros têm largura fixa em muitos arrays; ultrapassar limite pode produzir comportamento diferente de `int` Python. Para dinheiro, siga política decimal adequada, não troque para float só para usar vetorizações.

# pandas para tabelas
## DataFrame tem linhas e colunas
pandas organiza dados tabulares em `DataFrame`, com rótulos de colunas e índice de linhas. Instale no projeto com `uv add pandas` e use `import pandas as pd`. Comece por dados pequenos cujo resultado possa ser conferido no papel. `DataFrame` não é banco de dados: pode consumir muita memória e não oferece transações de negócio por si só.
## Criar uma tabela
```python
import pandas as pd

vendas = pd.DataFrame({
    "produto": ["A", "B", "A"],
    "valor": [10, 15, 20],
})
print(vendas.groupby("produto")["valor"].sum())
```
A tabela soma valores por produto. Antes de aceitar o resultado, confira manualmente A = 30 e B = 15. Em dados reais, veja tipos, ausências e duplicações. Uma tabela pode parecer correta visualmente e ter números guardados como texto.
## Ler e inspecionar
`pd.read_csv("vendas.csv")` lê CSV conforme opções de separador, codificação e decimal. `head`, `info`, `dtypes` e `isna().sum()` ajudam a conhecer os dados. Não comece pelo gráfico; primeiro descubra o que cada coluna representa e se linhas faltam. Preserve arquivo bruto para repetir análise. Em empresa, documente origem, data de extração e autorização de uso.
## Selecionar com loc
`vendas.loc[vendas["valor"] > 10, ["produto", "valor"]]` filtra linhas e escolhe colunas. `loc` usa rótulos; `iloc` usa posições. Parênteses nas condições compostas evitam erros com operadores vetoriais: `(a > 0) & (b == "x")`. Não use `and` diretamente entre séries. Revise a quantidade de linhas antes e depois do filtro; queda inesperada pode esconder dados importantes.
## Dados ausentes
Pandas representa ausência de maneiras dependentes do tipo e da origem. `dropna` remove linhas; `fillna` preenche, mas nenhuma decisão é neutra. Pergunte por que o valor está ausente e se preenchê-lo com zero altera significado. Em relatório empresarial, registre quantas linhas foram descartadas e qual regra foi aplicada. A qualidade do resultado não supera a qualidade dos dados e das decisões de limpeza.
## Junções e duplicação
`merge` junta tabelas por chave. Se a chave aparece duas vezes em cada lado, o resultado pode multiplicar linhas. Use validação de cardinalidade quando possível e confira contagens. Escolha `inner`, `left` ou outra junção conforme pergunta de negócio. Um pedido sem cadastro de cliente pode desaparecer num `inner`; isso não significa que ele nunca existiu. Preserve evidência das linhas não casadas.

# Matplotlib e comunicação de dados
## Um gráfico responde pergunta
Antes de escolher barras ou linha, escreva a pergunta: comparar categorias, mostrar evolução temporal ou observar distribuição? Matplotlib cria figuras e eixos; o padrão explícito `fig, ax = plt.subplots()` facilita personalização. Instale com `uv add matplotlib`. Um gráfico bonito pode induzir interpretação errada se escala, unidade ou dados ausentes não forem claros. Revisão visual faz parte da análise.
## Barras simples
```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots()
ax.bar(["A", "B"], [30, 15])
ax.set_ylabel("Vendas (R$)")
ax.set_title("Total por produto")
fig.tight_layout()
fig.savefig("vendas.png")
```
O código salva imagem no ambiente local. No navegador deste livro, Canvas ilustra conceitos sem instalar Matplotlib; para executar o exemplo completo, use seu projeto Python. Inclua fonte e período dos dados ao apresentar a figura.
## Eixos e limites
Uma escala cortada pode exagerar diferença. Para barras, começar o eixo de valores em zero geralmente facilita comparação de magnitude. Para série temporal, limites escolhidos podem destacar um intervalo, desde que sejam transparentes. Rotule unidades e legendas; não dependa apenas de cor. Usuários com daltonismo ou leitor de tela precisam de contraste, descrição textual e, quando possível, tabela alternativa.
## Linha para tempo
`ax.plot(datas, valores)` pode mostrar tendência, mas pontos ausentes e intervalos irregulares exigem tratamento. Ordene por data antes, não conecte categorias sem sentido temporal. Em indicadores empresariais, compare janelas equivalentes e anote mudança de definição da métrica. O gráfico representa escolhas de coleta e agregação; elas devem ser documentadas junto à imagem.
## Distribuição e outliers
Histograma mostra frequência por intervalos; a escolha de bins muda aparência. Boxplot resume mediana, quartis e pontos extremos, mas não explica sozinho causa. Um valor alto pode ser erro ou caso legítimo. Investigue antes de removê-lo. Para poucos dados, uma tabela pode comunicar melhor. Faça sempre uma descrição em palavras da conclusão e da incerteza.
## Fluxo reprodutível
Guarde script, fonte e versão das bibliotecas. Uma figura produzida manualmente num notebook sem execução limpa pode depender de estado antigo. Reinicie e execute tudo na ordem antes de entregar. `fig.savefig` cria artefato compartilhável; verifique tamanho, textos e cores em celular. Não publique dados pessoais só porque estão “apenas num gráfico”.
